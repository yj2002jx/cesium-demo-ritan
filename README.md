# 日坛三维可视化项目 | Cesium WebGIS Demo
## 项目简介
基于Cesium原生JS开发三维GIS可视化页面，用于展示WebGIS三维前端开发能力。
> 技术栈：原生JavaScript、Cesium、GeoJSON

## ✨ 功能清单
1. 三维地球场景初始化加载
2. 多底图图层切换（天地图矢量/影像）
3. 地图要素点击查询属性弹窗
4. 缓冲区空间分析可视化
